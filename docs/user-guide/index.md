# User Guide

This section is for people who submit scientific tasks and read their results.
It covers the submission contract, the task lifecycle, and how results are
delivered and inspected.

## Pages

- [Submitting Tasks](submitting-tasks.md) — discover capabilities, use the web
  interface, and submit through the API.
- [Task States and Result Delivery](task-states.md) — lifecycle states, what
  `finished` guarantees, and how artifacts become inspectable.
- [Results](results.md) — authenticated manifests, downloads, and the generic
  fallback.
- [Access and Runner Availability](access-and-runner-availability.md) — why
  readiness and entitlement are separate from your ability to submit.

If you operate the server rather than use it, start with the
[Operator Guide](../operator-guide/index.md).
