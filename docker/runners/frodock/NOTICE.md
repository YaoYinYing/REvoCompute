# FRODOCK third-party notices

The SIF redistributes binaries built by the FRODOCK authors and shipped in
`frodock3_linux64.tgz`. That archive contains no `LICENSE` file, so the
definition writes the BSD 3-Clause text published at
`https://chaconlab.org/downloads/License.txt` to
`/opt/frodock/LICENSE.txt` and keeps the upstream `README.md` and
`user_guide.md` alongside it. An operator inspecting the image can therefore see
both the terms and the upstream instructions without leaving the container.
